## 三、无 Key 时的提示（真实模式）

```text
$ python scripts/trade_demo.py
FATAL: 环境变量 IMZHUGE_API_KEY 未设置。
获取：网页端 https://m.imzhuge.com → 登录 → 个人中心 → API Key → 生成（pm_ 开头）
设置：macOS/Linux  export IMZHUGE_API_KEY="pm_你的key"
      PowerShell  $env:IMZHUGE_API_KEY = "pm_你的key"
      Windows永久 setx IMZHUGE_API_KEY "pm_你的key"（重开终端生效）
（无 Key 可先用 --mock 离线体验完整链路：python trade_demo.py --mock）
注意：Key 可交易积分，勿粘贴进对话/代码/笔记；泄露立即网页端轮换。
```

## 四、W0 开场速览卡（agent 展示格式）

```markdown
✅ 连接正常 | 服务器: m.imzhuge.com

📊 可交易市场（进行中的比赛 8 场，其中 2 个市场在交易窗口内）:
  · 科创50指数11-20涨跌幅预测   <-5% 0.43 / ±5%区间 0.47 / >+5% 0.11   截止 11-20 15:00
  · 某球员冬窗转会预测           转会成功 0.62 / 留队 0.38               截止 12-01 23:59

💰 余额: 活动诸葛贝 30.00（科创50活动）| 专属积分 100.00（转会活动，隔离赛不联动全局）| 全局 36.17
📈 持仓: 无（有持仓时列：合约/份数/成本/现价/浮动盈亏）
```

（隔离赛余额口径：专属积分不联动全局，`my_holdings` 对隔离赛可能不返回 `total_money`，需全局诸葛贝时用 `my_balance` 查询并标注"隔离赛不联动全局"。）

## 五、典型错误场景

```text
# Key 无效（HTTP 401）
FATAL: API Key 无效或已过期（HTTP 401）。

# 未加入活动（warning，不是错误）
  [未加入] 您尚未加入该活动，暂无余额（需先在网页端加入活动）

# 下单失败（参数/校验类，修正参数后可重发）
  失败：您的余额不足！
  （注意：执行类失败禁止自动重试；请先查持仓确认实际状态）
```
